## PRE-READ (kept LIGHT — R2: don't overload the caller)
1. **Primary genre — a SINGLE label** (발라드 / 아이돌-댄스 / K-hiphop / 트로트 / K-R&B / Hybrid-vibe). Do NOT force P%/S%/D% math unless a classifier gives confidence (else judges hallucinate genre math).
2. **화자 (persona)** — a constructed speaker (generation 10대/40대 · gender · situation) via diction + **종결어미** + stance + 진심; dialect-persona (경상 사투리 어미) when deliberate. Subject-omission = deliberate 여백 vs confusion.
3. **Optional notes** (only when obvious): section-roles (verse/chorus/rap-break/bridge, ≤4 buckets); **Hybrid/분위기 modifier** — does only two things: lowers narrative-depth expectation, raises texture/repetition/persona-vibe relevance. All genre reweighting happens INSIDE the dimensions below, not as a heavy pre-scan.

## CORE RULES
1. **Count SYLLABLES (음절); 1 음절 ≈ 1 note is a working assumption, NOT a scoring principle.** Do NOT reference the Japanese-import 7·5 음보 (Korean native cadence is 3·4/4·4). Text scores syllable PARITY + gross over-cramming; the sung fit is AUDIO.
2. **⭐ NO lexical tone/accent penalty (drop JA accent×melody + ZH 倒字).** 종결어미 intonation is phrase-micro, NOT the macro melodic arc — do NOT judge "collision with the hook arc" from text (K-pop clashes intonation for attitude on purpose — NewJeans deadpan). Melody-collision + homophone-friction (밤/밤이) = [AUDIO-FLAG]. **Dialect flavor = scored PERSONA craft in D1/D5 when deliberate** (자이언티〈양화대교〉).
3. **Rhyme genre-gated + demoted.** Ballad/trot/pop: rhyme NEUTRAL, don't score (penalize only forced/awkward). K-hiphop: score **flow-rhyme integration** + 모음/다음절/한영 + 펀치라인/언어유희(meaning) > rhyme(sound). ⚠ 어미(suffix) rhyme is "lazy" ONLY when sole/meaningless — a master (버벌진트) rhymes inside 어미 chains; don't auto-penalize.
4. **Function-before-feature.** Any device scores only if it advances the speech-act. Ornament w/o function = 0.
5. **Craft ≠ Reach + GENRE-CONDITIONAL FLOOR.** Two scores, never averaged. A hook (Reach) can't rescue an empty lyric — BUT the D1/D4 floor is **genre-conditional** (R2): STRONG for 발라드/SSW; for idol-dance/Hybrid-vibe SOFTENED if D5/D6/D7 show strong persona + phrase-economy + repeatable verbal identity (aespa〈Next Level〉 = cyber-persona/slogan is valid craft, not "empty"); for K-hiphop replaced by character/stance/punchline coherence; for 트로트 archetypal sentiment OK if delivery-persona is clear. Reach = 대중성 = HYPOTHESIS.

## THE SEVEN DIMENSIONS

### D1 — 화자·명확성 (Persona & Clarity)  [TEXT✓]
Coherent **constructed** narrator (generation/gender/stance) from diction + 종결어미; **종결어미 SEQUENCE coherence** (plain→banmal→honorific = a coherent stance-shift, not salad); everyday-observation specificity; 진심; dialect-persona consistency. **Penalize:** personality-less/generation-less "AI narrator"; confusion as depth.

### D2 — 음절 구조 (Syllable Architecture / Textual Articulation Load)  [TEXT✓ structural ONLY]  ★no climax/singability
- **[TEXT✓] pure structural (spreadsheet-able):** cross-section syllable PARITY (1절/2절 count match); gross over-cramming relative to visible section type; consonant-cluster complexity / tongue-twister collisions; 조사/어미 padding. **Report 받침(coda) load as a NEUTRAL metric — NOT a red-flag** (closed codas are craft: 응축 in 성시경〈거리에서〉, "gut" in 트로트, brake per 심현보).
- **[AUDIO-FLAG] not scored:** which line is climax/hook-focal, whether a 받침 lands on a held/high note, open-vowel suitability at climax, real 연음, melisma, "does it sing".

### D3 — 음향·모음조화·라임 (Sound, Vowel-Harmony & Rhyme)  [TEXT✓]
- **[TEXT✓] 모음조화 + ideophones** (scored in 의성/의태/hook phrases with 원문 evidence; elsewhere sound-texture sub-basis, cap 6 if sound-only-no-meaning): 양성/음성 affect (반짝 vs 번쩍), apt 의태어, 어감, 두운.
- **[TEXT✓] rhyme = K-hiphop only** (Rule 3): flow-rhyme integration + 모음/다음절/한영 + 펀치라인.

### D4 — 정서·서사 (Emotion & Narrative)  [TEXT✓]  (longevity moved to D7)
1. **起動 Trigger:** concrete emotional trigger (object/장면/대사/situation), not abstract feeling-word dump.
2. **전개 Turn:** feeling transforms/deepens (real pivot or effective 여백) vs restating; 한/서사 for ballad/trot. **⚠ genre-note:** atmosphere/vibe genres (NewJeans-style) legitimately have NO big turn — do NOT demand one; judge the mood/withheld-confession execution instead.
3. **필연 Necessity:** is the emotional route necessary for THIS song+persona+genre?
- **Penalize:** generic AI-罐頭 emotion fitting 100 songs; route mismatch (but NOT "no turn" in a vibe song).

### D5 — 언어·한영·문체 (Diction, Code-mixing, Style)  [TEXT✓]
口語 naturalness vs stiffness vs 설교조; register + 세대 fit; **한영 혼용** judged by 어감/groove-fit + FUNCTION for a Korean listener (NOT English grammar — never dock Konglish; but non-functional filler-English IS docked); **종결어미/문체** (명사형·부름말); dialect diction as persona; originality.

### D6 — 후크·기지 (Hook-craft & Wit)  [TEXT✓ verbal design / AUDIO-FLAG earworm]
- **[TEXT✓]:** is the repeated 훅/후렴 short, vivid, well-designed (title-worthy, payoff not buried), the *phrase* repeatable; **펀치라인/언어유희** wit; economy.
- **[AUDIO-FLAG]:** actual 중독성/earworm is melody-driven — text judges the hook's VERBAL design, never scores "catchiness".
- Genre: hook Reach-lean for idol; lower for ballad/trot. (No numeric caps — the genre-conditional floor in Rule 5 does the balancing.)

### D7 — 여운·재청취 가치 (Residue & Re-listen Value)  [TEXT✓ as text-complexity — honestly caveated]  ★NEW (R2 unanimous)
Does a NON-hook line reward the 5th listen? Judge TEXT properties only: a quotable stand-alone line (Epik High verses; 아이유〈밤편지〉 restraint), image density, ambiguity that opens on re-read, deliberate 여백/withholding, 정(attachment)-building interiority beyond the hook (김이나's "the room behind the door"). **⚠ HONESTY CAVEAT:** this scores textual depth/complexity/여백, NOT measured listener-retention (which needs the melody + real audiences) — label it a text-complexity signal, not a retention metric.
