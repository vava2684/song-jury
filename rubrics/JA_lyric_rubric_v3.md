## PRE-READ 1 — GENRE VECTOR + TROPE-SUBVERSION  (replaces the rigid table; R2 fix)
Detect ≥3 markers → output a **weighted genre vector**, not one box:
`Primary genre P% · Secondary S% · Device-mode D%` (e.g. Creepy Nuts「BBBB」= J-rap 60% · idol-chant 30% · net-meme 10%). Each dimension's emphasis is a **weighted blend** of the genres present — no hard swap. Max 2 genres + 1 device-mode.
- **Per-genre emphasis (blend, don't lock):** 演歌→D3語感/D4情念型内; J-pop/SSW→D4叙景・語り/D3母音連鎖; idol/uptempo→Reachフック/街鳴り; **J-rap→D3多層母音韻×意味(Reach加重)**; ボカロ/net→D2=情報密度(歌唱可能性ではない)/D6視覚表記.
- **TROPE-SUBVERSION check (replaces "Forbidden misread"):** genre tropes (演歌の雪/酒/海; idol 一人称少女; rap パンチライン) are **immune to auto-cliché ONLY IF subverted or made to function**; **passive AI pastiche of the trope = penalize**. Convention mastered ≠ convention recycled (阿久悠 時代の飢餓感 test; 藤原定家 本歌取り = transform not repeat).

## PRE-READ 2 — 語り手 (PERSONA) LOCK
Narrator via **一人称**(僕/俺/私/あたし/omitted) + **終助詞**(ね/よ/さ/わ/かな) + stance. **主語省略・余白 = FEATURE**: judge deliberate openness (craft) vs referential confusion (weak). **視点の滑走** (君/僕 shifting between verses; 中島みゆき「ファイト!」multi-narrator) = HIGH craft when STRUCTURAL. **Genre persona templates**: 演歌's fixed 私/あなた+ね/よ is 職人的定型 — flat only if 情念の階層 is missing, NOT because it's conventional (do not auto-flag convention as "AI-flat").

## CORE RULES
1. **Count MORA** (拗きゃ=1, 撥ん=1, 促っ=1, 長ー=1). Singability = mora-to-note = **AUDIO-FLAG**.
2. **Function-before-feature.** Any device scores only if it advances the speech-act. Ornament w/o function = 0.
3. **脚韻 vs 母音の響き:** 脚韻 (line-final match) near-automatic → low info; forcing it outside rap = penalize. **母音連鎖/assonance/頭韻/語感 = traditional resource, scored ALL genres [TEXT✓].** Multilayer meaning-bearing rhyme = Reach weight **only J-rap** (川原/R-指定).
4. **分母分子 = holistic LENS (not scored):** in the verdict, read whether the lyric actively re-claims the imported form vs passive 翻訳調 — but its TEXT-observable tells live in D2, and the performed negotiation is [AUDIO-FLAG].
5. **Craft ≠ Reach** — two scores, never averaged. Reach's 時代の飢餓感/街鳴り is a market HYPOTHESIS, label as such.

## THE SIX DIMENSIONS

### D1 — 語り手・明晰性 (Narrator & Clarity)  [TEXT✓]
Coherent through-line + a *characterized* narrator (一人称/終助詞). **Reward:** locatable voice (age/gender/stance); *structural* 視点の滑走; deliberate 主語省略/余白. **Penalize:** personality-less "AI narrator" (no committed 一人称, 終助詞 as random garnish); referential confusion posing as depth. **AI-flat tell** = particle-salad + genderless/ageless speaker.

### D2 — 拍・構造リズム (Mora-Rhythm & Structure)  [TEXT✓ architecture / AUDIO-FLAG note-fit]
- **[TEXT✓]:** mora-count consistency & correspondence across parallel sections (1番/2番); deviation pattern vs 7-5 / 8-mora (Bekku) baseline; special-mora (っ/ん/ー) distribution; is 字余り/字足らず a *repeated intentional* pattern. **Form/structure:** verse→chorus information gradient (叙述→凝縮), keyword-anchor design (「Lemon」型).
- **翻訳調 text-tells** [TEXT✓]: unnatural inversion, English-calque abstraction, dropped-particle awkwardness, lines too long to breathe as Japanese, line-final English-pop mimicry with hollow content → lower Craft.
- **[AUDIO-FLAG] not scored:** actual 譜割り note-fit, one-mora-per-note, melisma, sung singability, performed form-negotiation → "要音源".
- **Genre blend:** ボカロ/net → this axis = information-density/readability, high density = strength; but penalize meaningless 助詞/漢語 padding (言葉の空転).

### D3 — 音韻・語感 (Sound & Word-Feel)  [TEXT✓ / accent AUDIO-FLAG]
- **[TEXT✓]:** 母音連鎖/assonance; **語感・音象徵** (清/濁/促 emotional mapping キラキラ↔ギラギラ; オノマトペ); 頭韻; J-rap → multisyllabic/hidden vowel-rhyme AND rhyme-carries-meaning (川原: 韻×意味 vector, not rhyme-for-rhyme).
- **[AUDIO-FLAG]:** pitch-accent×melody agreement — text can only FLAG homophone-mishearing risk (帰る/変える, 橋/箸 密集 → "誤聴リスク・音源審査へ"). Never a number.
- Don't reward meaningless vowel-filler; don't dock a ballad for no rhyme.

### D4 — 情動の起動と転 (Emotion: Trigger & Turn)  [TEXT✓]  (execution, NOT taxonomy)
Score whether emotion is GENERATED and MOVES — three items, not a mode-checklist:
1. **起動 Trigger:** is there a concrete emotional trigger (object/台詞/scene/reframe/social-situation), not an abstract emotion-word dump?
2. **転 Turn:** does feeling transform/deepen across the song — a real pivot (A叙景→サビ告発; 中島みゆき), or effective 余白/主語省略 — vs merely restating one feeling?
3. **必然 Necessity:** is the chosen route (叙景/告白/演説/呪文/反復/synecdoche) necessary for THIS song+persona+genre?
- **Reward:** a single image carrying the arc (marigold/lemon — memory-synecdoche, full credit w/o street-detail); a clean turn; abstract-word-as-functional-chant (サビ「ファイト!」) when it works.
- **Penalize:** generic AI-罐頭 emotion that fits 100 songs (bites regardless of which "mode" is claimed); route that doesn't fit; flat/no turn. 叙景-specificity is the primary anti-cliché test in 叙景-genres, not a universal absolute.

### D5 — 声・語彙・自然度 (Voice, Diction, Naturalness)  [TEXT✓]
口語 naturalness vs stiffness vs **説教臭さ**; vocabulary-layer register (和語/漢語/外来語) fit to genre; **日英 code-mixing** on sound/rhythm fit + code-ambiguation, **NOT grammar** — never dock 和製英語; but distinguish sloppy 文法破綻 from deliberate 言語遊戯 (R-指定). Diction originality (あいみょん natural-without-cliché). **Reward** natural spoken JP that still scans; **penalize** preachy over-explanation, textbook-stiff where colloquial is wanted.

### D6 — 機知・表記・重層 (Wit, Script & Layering)  [TEXT✓ core / furigana source-conditional]  (merges old D6+D7)
- **[TEXT✓] core:** 掛詞 (pivot-pun, two meanings zero length), 縁語 (associative web), 本歌取り (transforming allusion), ダブルミーニング, **economy 凝縮** (阿久悠 image-economy; ≠ merely short); **script-switch** (漢字/ひらがな/カタカナ: 君/きみ/キミ = distance/age/genre; カナ連打 = 機械的高速; visual rhythm/density) — this IS text-judgeable and is the real 表記 craft.
- **[SOURCE-FLAG bonus]:** 振り仮名/当て字 second-reading (地球→ほし) — score ONLY if the source text preserves ルビ; if absent (SUNO plain-text usual), flag "ルビ欠落・当該項目は評価対象外", do NOT fill with median.
- **Penalize:** wordplay/script without function; padding; unreadable 当て字 with no payoff; AI-ish random 表記ゆれ.

## SCORING & OUTPUT
- Each dim: **Craft 0–10 / Reach 0–10** + verbatim 原詞 evidence + one-line reason + **[TEXT✓/TEXT~/AUDIO-FLAG] label**.
- **Trope-immunity + function-penalty** (per PRE-READ 1): immune to convention IF subverted/functional; penalize passive pastiche.
- **Holistic override:** whole vs parts by **bounded ±1.5** w/ 3-part justification. **Trigger criterion (R5/ERNIE):** the override applies ONLY when a single dimension's failure is so severe it collapses inter-dimensional coherence (e.g. D1 incoherent → D4 emotion-arc becomes unreadable) — NOT for taste-based rebalancing. A dim crushing another (coherence failure) is NOT a win. Read 分母分子 here (翻訳調 vs live re-claiming) as a lens.
- Output: genre-vector + 語り手 up top → dual-score table (6 dims, w/ TEXT-labels) → 3-node emotion → **## 合議庭裁決 (Panel Verdict)** (strongest craft / hardest flaw / release rec; takes a stance; genre-aware).
