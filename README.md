# 原創歌曲自動評分系統

一套用 Python 寫的歌曲自動評分工具,不需要參考原曲,直接分析音檔的物理特徵來評分。適合評原創作品、Demo、編曲練習。

## 運作原理

程式沒辦法「聽懂」音樂好不好聽,但可以精準量測聲音的物理特徵。系統的做法是:先自動偵測歌曲的**調性**(key)和**節拍**(beat grid),把這兩者當成整首歌的內部基準,再量測演唱與混音的各項客觀指標,換算成 0–100 分後加權。

因為是「無參考基準」模式,評的是穩定度、一致性、音質、混音品質這類**絕對指標**,而不是跟某個標準答案比對。

## 安裝

需要 Python 3.9 以上。

```bash
pip install librosa numpy soundfile pyloudnorm praat-parselmouth
```

其中 `pyloudnorm`(響度量測)和 `praat-parselmouth`(嗓音品質)是選用的——沒裝的話,那兩項會自動略過並重新分配權重,其他照跑。

## 用法

```bash
# 只評「編曲混音」(最簡單,只要一個混音檔)
python song_scorer.py mix.wav

# 完整評分:另外提供人聲軌,才會評「演唱表現」
python song_scorer.py mix.wav --vocal vocal.wav

# 自動人聲分離(需另外 pip install demucs,第一次會下載模型)
python song_scorer.py mix.wav --demucs

# 輸出 JSON 報告(方便接後續程式或存檔)
python song_scorer.py mix.wav --vocal vocal.wav --json report.json

# 自訂權重
python song_scorer.py mix.wav --weights my_weights.json
```

支援 WAV、MP3、FLAC 等常見格式。

## 評分維度

### 演唱表現(需要人聲軌)

| 維度 | 量測方式 | 預設權重 |
|------|----------|:---:|
| 音準 | 每顆音貼合半音格線的音分偏差(80%)+ 落在調內的比例(20%) | 30% |
| 節奏 | 音符起點對節拍網格的**一致性**(扣掉系統性提前/延後) | 15% |
| 長音穩定 | 持續音的音高波動(MAD,有顫音的音不計入) | 15% |
| 顫音 | FFT 偵測 3.5–8.5 Hz 的規律波動,評速率與深度 | 10% |
| 動態控制 | 有聲段的響度起伏範圍 | 10% |
| 嗓音品質 | jitter / shimmer / HNR(需 parselmouth) | 10% |
| 音域 | 實際唱到的音高跨度 | 10% |

### 編曲混音(用完整混音即可)

| 維度 | 量測方式 | 預設權重 |
|------|----------|:---:|
| 整體響度 | 積分 LUFS(對照串流平台目標) | 15% |
| 動態範圍 | 峰值與均方根的比值(crest factor) | 20% |
| 頻譜平衡 | 四個頻段(低/中/中高/高)的能量占比是否落在合理窗口 | 20% |
| 立體聲寬度 | side/mid 能量比與左右聲道相關係數 | 10% |
| 削波檢測 | 觸頂取樣點的比例 | 10% |
| 層次鋪陳 | 把歌分 8 段,量段落間的能量與音色對比 | 15% |
| 和聲豐富度 | 諧波分離後的音級數 + 和聲變化率 | 10% |

演唱與混音的總權重預設是 55% : 45%。

## 等級

| 分數 | 等級 |
|------|:---:|
| 90–100 | S |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 60 以下 | D |

## 自訂權重

建一個 JSON 檔,只要列出想改的項目即可,沒列到的沿用預設:

```json
{
  "overall": { "vocal": 0.7, "mix": 0.3 },
  "vocal": {
    "pitch": 0.4,
    "rhythm": 0.2,
    "vibrato": 0.05
  }
}
```

例如做「歌唱比賽」評分,可以把 `overall.vocal` 調高、`pitch` 和 `rhythm` 加重;做「編曲比賽」則反過來。

## 重要限制

**不評主觀維度。** 情感表達、編曲創意、歌詞好壞這類東西,純規則寫不出來,需要大量人工評分資料去訓練機器學習模型才可能做,而且準確度仍有限。這套系統專注在客觀、可量測的面向。市售的 K 歌評分(全民K歌、卡拉OK機)其實核心也只有音準加節奏兩項而已。

**音準以「偵測到的調性」為準。** 系統假設歌曲有明確調性、且演唱應該貼合半音格線。爵士、藍調、微分音音樂這類刻意離調或滑音很多的曲風,分數會偏低,需要斟酌看待。

**需要乾淨的人聲軌才能評演唱。** 如果只有混音檔,可以用 `--demucs` 自動分離,但分離品質會影響音高追蹤的準確度。有原始人聲軌(錄音時的獨立軌)最準。

**適合相對比較,不適合當絕對真理。** 同一批作品用同一套權重跑,分數高低的排序是有意義的;但「85 分」本身不代表任何絕對的音樂價值。

## 升級方向

如果想讓系統更強,幾個可以走的路線:

- **音高偵測換 CREPE**:目前用 librosa 的 pyin,換成深度學習的 CREPE 會更準,尤其在雜訊多的錄音上。
- **人聲分離內建 Demucs**:把 `--demucs` 從選用變成預設流程,讓使用者只丟一個混音檔就能完整評分。
- **加入咬字分析**:用 Whisper 把歌詞強制對齊,以辨識信心度近似咬字清晰度。
- **主觀維度用 ML**:蒐集人工評分資料,訓練模型來預測情感表達、編曲質感這類主觀分數。這是最難但最有價值的一步。
- **和弦進行辨識**:目前和聲只評豐富度,可以進一步辨識實際和弦進行,評和聲的合理性與巧思。

## 檔案說明

- `song_scorer.py` — 主評分引擎
- `make_demo_song.py` — 合成一首測試歌曲(產生 `demo_vocal.wav` 和 `demo_mix.wav`),用來驗證系統跑得通、也可當作各指標的參考基準
