# 第三個環境 .venv-audition —— 新柱管線(演唱聽感 SingMOS + 真實距離 MuQ + AI 感 SONICS)
#
# 為什麼要獨立一個 venv:這三個模型的 torch/transformers 版本與 .venv-ml(SongEval/Audiobox)
# 相衝,硬裝同一個環境會互相踩死。三個環境各司其職是實測後的結論,不是潔癖。
#
# 安裝(Windows PowerShell;Linux/macOS 把 Scripts 換成 bin):
#   python -m venv .venv-audition
#   .\.venv-audition\Scripts\pip install -r requirements-audition.txt
#   .\.venv-audition\Scripts\pip install "git+https://github.com/awsaf49/sonics.git"
#
# ⚠️ 這裡**刻意不寫 --extra-index-url**。torch 要用哪個索引(cu124 / cpu / macOS 官方)
#    由安裝腳本偵測 GPU 後用 --index-url 傳進來。
#    ⛔ 曾經在這裡寫死 cu124,結果:
#       (a) uv 預設 first-index 策略 → numpy 在 cu124 索引上「有套件、沒這個版本」,
#           整份 requirements 直接 No solution found,全平台裝不起來;
#       (b) macOS 根本沒有 cu124 wheel,Mac 使用者必失敗;
#       (c) 沒有 NVIDIA 卡的人被硬灌 CUDA 版 torch,白下載 2.5GB。
#    自己手動裝的話請照 https://pytorch.org/get-started/locally/ 選對索引。
#
# 權重會在第一次執行時自動下載(SingMOS 走 torch.hub、MuQ 走 HuggingFace),合計約 3 GB。
